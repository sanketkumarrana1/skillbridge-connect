# AcadIn — Intelligent Academia–Industry Collaboration & Placement Ecosystem

**AcadIn** is a comprehensive, multi-role educational and recruitment platform that bridges verified student skills with live industry opportunities, curriculum intelligence, and institutional accreditation analytics.

---

## 🌟 Ecosystem Workspaces

1. **Student Suite**:
   - Dynamic Skill Passport with multidimensional competency vectors.
   - AI-adaptive 20-question assessments with automated scoring & instant feedback.
   - ATS Resume Builder, Certificate manager, and verified Placement Timeline.
   - High-fit opportunity matching with transparent eligibility scoring.

2. **Industry & Recruiter Suite**:
   - Direct opportunity posting with required/preferred skill weights and batch cutoffs.
   - Searchable student candidate talent pool with Skill Passport inspection.
   - AI-powered candidate summaries, interview scheduling, and offer letters.

3. **Academician / Faculty Suite**:
   - Faculty profile, research publications, and FDP / industry training opportunities.
   - Student mentorship management with conflict-free calendar booking.
   - Research & consultancy collaboration pipelines with corporate sponsors.

4. **Institution Intelligence**:
   - Campus placement rate metrics, department breakdown, and skill gap reports.
   - Real-time industry skill demand tracking for curriculum updates and NBA/NAAC accreditation.

5. **Platform Admin & Moderation**:
   - Global moderation queue for opportunities, company verifications, and skill taxonomy.
   - Multi-tenant audit logging and platform telemetry.

---

## 🛠️ Technology Stack

- **Frontend**: React 19, TypeScript 5.8, Tailwind CSS, TanStack Router & Start, Lucide Icons, Recharts.
- **Backend & Database**: Supabase PostgreSQL with 67 production migrations, Row Level Security (RLS), and database triggers.
- **AI Intelligence**: Google Gemini Flash via Supabase Edge Function Gateway with deterministic zero-cost fallbacks.
- **Testing**: 42 automated tests covering scoring, matching, state machines, and cross-role recruitment journeys.
- **Deployment**: Vercel Global Edge Network with SSL and SSR Nitro runtime.
